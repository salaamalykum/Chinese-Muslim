# Contributing to Chinese Muslim Knowledge Base

Thank you for your interest in contributing! This project is maintained automatically via the Project Iqra pipeline, but we welcome community contributions.

## How to Contribute
1. **Reporting Issues**: If you find any malformed Markdown, missing metadata, or parsing errors, please open an Issue.
2. **Fixing Metadata**: You can submit a Pull Request to correct the YAML frontmatter in any of the articles under `/content/`.
3. **Adding RAG Queries**: Contributions to the `/docs/` notebooks or testing scripts are highly encouraged.

Please ensure all PRs maintain the strictly typed data dictionaries defined in our dataset card.
